# نظام إدارة المهام — TaskFlow

نظام متكامل لإدارة مهام الفريق، بديل لشيت «متابعة تاسكات». يغطي إسناد المهام، وقبولها أو رفضها، وتسليمها ومراجعتها، وطلبات تمديد المواعيد واعتمادها، والإشعارات، والتقارير، وسجل نشاط لا يمكن تعديله.

**التقنيات:** Next.js 15 + TypeScript + Tailwind (واجهة عربية RTL) · Supabase (قاعدة بيانات Postgres + تسجيل الدخول + التخزين) · Vercel للاستضافة.

---

## التشغيل لأول مرة (حوالي 15 دقيقة)

### 1) إنشاء مشروع Supabase
1. من supabase.com أنشئ مشروعًا جديدًا (منفصلًا عن kingdom-leads).
2. افتح **SQL Editor** ونفّذ الملفات الموجودة في `supabase/migrations/` **بالترتيب**:
   `0001_schema.sql` ← `0002_functions.sql` ← `0003_security_views_seed.sql` ← `0004_supabase_platform.sql`
   - الملف `0004` يفعّل المرفقات والإشعارات الفورية وفحص المواعيد كل ساعة (pg_cron). لو ظهر خطأ في سطر `pg_cron`، فعّل الإضافة من **Database → Extensions → pg_cron** ثم أعد تنفيذ آخر سطرين.
3. من **Authentication → Providers** تأكد أن Email مفعّل. ويُفضّل إيقاف «Allow new users to sign up»، لأن الحسابات ينشئها مدير النظام فقط.
4. من **Project Settings → API** انسخ: `Project URL` و`anon key` و`service_role key`.

### 2) تشغيل الكود محليًا
```bash
npm install
cp .env.example .env.local      # واملأ القيم الثلاث
node scripts/create-admin.mjs "منار حسني اسماعيل عبد الرحمن" you@email.com "كلمة-مرور-قوية"
npm run dev                      # http://localhost:3000
```

### 3) نقل بيانات الشيت
ادخل بحساب المدير، ثم **الإعدادات ← استيراد من الشيت ← «استخدم نسخة الشيت المرفقة مع النظام»**. ستظهر لك معاينة لكل موظف، ويمكنك فيها تقسيم أي خلية أو دمجها، واستبعاد أي مهمة. بعد ذلك اضغط «تنفيذ الاستيراد». يمكنك أيضًا رفع نسخة Excel أحدث من الشيت في أي وقت، ولن تتكرر المهام المستوردة سابقًا. الشيت الأصلي لا يتم تعديله.

بعد الاستيراد:
- **الإعدادات ← الأقسام:** أنشئ الأقسام وحدد قائد كل فريق.
- **الإعدادات ← أعضاء الفريق:** حدد قسم كل موظف ودوره، وأنشئ له حساب دخول (بريد إلكتروني وكلمة مرور مؤقتة).
- حدد الموعد النهائي للمهام المستوردة التي ليس لها موعد، من زر «تعديل» في صفحة المهمة.

### 4) النشر على Vercel
اربط المستودع بـ Vercel، وأضف متغيرات البيئة الموجودة في `.env.example`، وضع `NEXT_PUBLIC_SITE_URL` على رابط الموقع. ومن Supabase ← **Authentication → URL Configuration** أضف نفس الرابط في Site URL وRedirect URLs، حتى تعمل رسائل استعادة كلمة المرور.

## الأدوار والصلاحيات
| | مدير النظام | قائد فريق | موظف |
|---|---|---|---|
| عرض المهام | الكل | مهام فريقه + ما أنشأه | مهامه فقط |
| إنشاء وإسناد وإعادة إسناد | ✓ | لأعضاء فريقه | — |
| قبول/رفض الإسناد، التنفيذ، التسليم، طلب تمديد | — | — | ✓ (لمهامه) |
| مراجعة واعتماد المهام | ✓ | ✓ (لا يراجع مهمة مسندة إليه) | — |
| اعتماد التمديد | ✓ | إذا مُنح صلاحية «اعتماد طلبات التمديد» | — |
| الفريق، الأقسام، الإعدادات، الاستيراد | ✓ | — | — |

يمكن تعديل صلاحيات كل دور من «الإعدادات ← صلاحيات الأدوار»، ومنح صلاحية إضافية لشخص بعينه أو سحبها منه من صفحة العضو.

## قواعد مضمونة على مستوى قاعدة البيانات (وليس الواجهة فقط)
- كل كتابة تمر عبر دوال في Postgres تتحقق من الصلاحية ومن صحة الانتقال بين الحالات. المستخدمون لا يملكون صلاحية INSERT أو UPDATE أو DELETE مباشرة على أي جدول.
- لا يمكن بدء مهمة قبل قبولها، ولا إكمالها قبل المراجعة (إذا كانت تتطلب مراجعة).
- رفض المهمة يتطلب سببًا، وتعود المهمة للإدارة دون مسؤول.
- إعادة الإسناد تضيف سجلًا جديدًا (المسؤول السابق، والجديد، ومن قام بها، ومتى) ولا تمسح ما قبلها.
- الموعد الأصلي لا يتغير أبدًا (يمنعه Trigger حتى على صاحب قاعدة البيانات). الموعد المعتمد الحالي لا يتغير إلا باعتماد طلب تمديد. الطلب المعلّق لا يغيّر شيئًا.
- لا يمكن لأي شخص اعتماد طلب تمديد على مهمة مسندة إليه.
- المهام المكتملة أو الملغاة مقفلة. سجل النشاط وسجل الإسناد والتعليقات لا يمكن تعديلها أو حذفها.
- المهام لا تُحذف، وإنما تُلغى مع ذكر السبب.

```bash
npm run test:db
```

## الترجمة للإنجليزية
كل نصوص الواجهة موجودة في `lib/i18n/ar.ts`، والنسخة الإنجليزية في `lib/i18n/en.ts` (وأي نص غير مترجم يظهر بالعربية). لتشغيل الواجهة بالإنجليزية: `NEXT_PUBLIC_DEFAULT_LOCALE=en`، والاتجاه يتحول إلى LTR تلقائيًا. رسائل الأخطاء تخرج من قاعدة البيانات كمفاتيح (`err.*`) وتترجمها الواجهة.

## هيكل المشروع
```
supabase/migrations/   قاعدة البيانات: الجداول، الدوال، الصلاحيات، التخزين، المهام المجدولة
app/(app)/             الصفحات: لوحة التحكم، المهام، مهامي، إسناد المهام، الفريق، المشاريع، التمديدات، التقارير، الإشعارات، الإعدادات
components/            مكونات الواجهة
lib/                   الاتصال بـ Supabase، الجلسة والصلاحيات، الاستعلامات، الترجمة، محلل الشيت
data/sheet-export.csv  نسخة من شيت «متابعة تاسكات» كما هو (للاستيراد)
tests/                 اختبارات قاعدة البيانات والاستيراد
```
